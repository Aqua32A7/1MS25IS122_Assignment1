Paper Title: Attention Is All You Need

1. CORE CONCEPT SUMMARY
--------------------------------------------------------------------------------
Problem Statement:
Prior state-of-the-art sequence transduction models relied heavily on complex recurrent or convolutional neural networks connected via an attention mechanism. The sequential nature of recurrence precluded computational parallelization during training on GPUs and hindered learning long-range contextual dependencies due to vanishing gradients across distant positions.

Primary Methodology:
The authors propose the Transformer, a novel model architecture eschewing recurrence and entirely relying on an attention mechanism to draw global dependencies between input and output tokens. By mapping sequences in parallel, it drastically reduces training time while allowing direct connections across all sequence positions.

Algorithmic Contributions:
Key contributions include Scaled Dot-Product Attention with variance-stabilizing square-root scaling, Multi-Head Attention allowing the model to jointly attend to multiple representation subspaces, and sinusoidal positional encodings to inject sequence order without recurrence.

Key Findings:
On the WMT 2014 English-to-German and English-to-French translation tasks, the Transformer established new state-of-the-art BLEU scores while training significantly faster (in 3.5 days on 8 GPUs) than competitive recurrent or convolutional ensembles.

Plain-Language Explanation:
Instead of reading text word-by-word like a human reader, the Transformer looks at an entire sentence at once, calculating how much every word relates to every other word simultaneously, making training dramatically faster and capturing context across full sentences.

3. BUILD OPPORTUNITIES (STUDENT PROJECT EXTENSIONS)
--------------------------------------------------------------------------------

Project 01: Hybrid State-Space Transformer for Long-Sequence Document Modeling
* Proposed Modification: Replace quadratic O(N²) self-attention blocks in lower Transformer layers with selective linear state-space (Mamba) layers.
* Problem Addressed: Standard self-attention quadratic complexity imposes prohibitive VRAM bottlenecks on context lengths exceeding 4k tokens.
* Expected Benefit (Expected, not verified): Expected sub-quadratic memory scaling and expected increase in generation throughput on long document contexts.
* Success Metric: Targeting reduced peak GPU memory allocation and sustained decoding speed on sequence lengths up to 8,192 tokens with minimal loss in perplexity.
* Tech Stack: PyTorch, Hugging Face Transformers, Mamba-SSM, Weights & Biases
* Implementation Plan:
  1. Profile memory scaling of standard multi-head attention against sequence length.
  2. Swap intermediate encoder attention layers with causal Mamba selective state-space blocks.
  3. Fine-tune the hybrid checkpoint on long-context technical summaries and measure memory consumption.
* Evaluation Plan: Evaluate validation perplexity on long-form document datasets alongside profiling peak CUDA memory using torch.cuda.max_memory_allocated.

Project 02: Edge Deployment with Post-Training Weight-Activation Quantization
* Proposed Modification: Apply activation-aware 4-bit weight quantization (AWQ) and export the encoder-decoder graph to ONNX Runtime.
* Problem Addressed: Unquantized 32-bit floating-point weights exceed memory and bandwidth limits on resource-constrained ARM and embedded devices.
* Expected Benefit (Expected, not verified): Expected reduction in model storage footprint and expected latency improvements during CPU-bound inference.
* Success Metric: Targeting under 200MB memory footprint and real-time interactive generation latency on ARM64 processors with less than 0.5 BLEU score degradation.
* Tech Stack: ONNX Runtime, Optimum, PyTorch, C++
* Implementation Plan:
  1. Calibrate layer activations over a representative multi-lingual corpus.
  2. Quantize linear projection and feed-forward layers to 4-bit weights with 8-bit activations.
  3. Export model graph to ONNX Runtime and benchmark throughput on ARM CPU cores.
* Evaluation Plan: Compare BLEU translation scores and measure execution wall-clock time per generated token on ARM64 hardware.

Project 03: Speculative Decoding using a Lightweight Draft Model
* Proposed Modification: Pair the base Transformer model with a compact 2-layer autoregressive draft network to propose speculative token sequences verified in parallel by the target model.
* Problem Addressed: Autoregressive token-by-token generation is memory-bandwidth bound on GPUs due to repeated weight loading per token.
* Expected Benefit (Expected, not verified): Expected reduction in end-to-end wall-clock generation latency while mathematically preserving exact target model token probability distributions.
* Success Metric: Targeting an average acceptance rate of 2-3 tokens per draft proposal with zero degradation in output accuracy compared to greedy sampling.
* Tech Stack: PyTorch, vLLM, Hugging Face, CUDA
* Implementation Plan:
  1. Train a 2-layer draft head on the frozen hidden representations of the primary Transformer.
  2. Implement speculative verification logic accepting matching prefix tokens.
  3. Measure wall-clock latency per completed response under varied sequence lengths.
* Evaluation Plan: Measure acceptance length ratio (mean accepted draft tokens per verification step) and total inference speedup compared to standard autoregressive decoding.
